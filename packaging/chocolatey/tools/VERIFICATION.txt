VERIFICATION

Verification is intended to assist the Chocolatey moderators and community
in verifying that this package's contents are trustworthy.

VideoAbridge binaries are not embedded in this package. The install script
downloads the official Windows x64 zip from the matching GitHub Release:

  https://github.com/icalvo/VideoAbridge/releases

Asset name pattern:

  VideoAbridge-v{VERSION}-win-x64.zip

To verify:

1. Download the zip for this version from the GitHub Release assets.
2. Run: Get-FileHash -Algorithm SHA256 .\VideoAbridge-v{VERSION}-win-x64.zip
3. Confirm the hash matches checksum64 in tools\chocolateyInstall.ps1.

LICENSE file).
